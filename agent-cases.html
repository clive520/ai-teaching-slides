站在巨人的肩膀上：現成強大工具火力展示

老師們，前面我們學了怎麼判斷任務是否適合自動化。但在你捲起袖子自己寫程式之前，請先停下來！市面上其實已經有非常多現成、強大的 AI Agent 可以直接使用了。今天我們就來見識一下這些「超級助理」的火力！

案例一：Google Antigravity 開發助理

情境：從零建置教學網站

不只是寫 Code，而是「幫你執行」

Antigravity 是一個擁有強大系統權限的 Agent。你只要下達自然語言指令，他就能：

  • 自動讀取你的專案資料夾。
  • 自動編寫 HTML/CSS，並呼叫工具生成配圖。
  • 直接在終端機幫你下指令 (例如 Git 推送部署)！

💡 真實案例：您現在看到的這份教學網站，就是老師透過 Antigravity 自動產生的！

案例二：ChatGPT 資料分析 (Code Interpreter)

情境：學生成績單與問卷分析

把 Python 工程師藏在對話框裡

  • 傳統做法： 老師要自己學 Excel 函數、樞紐分析，甚至學 Python 爬蟲。
  • Agent 做法： 直接把凌亂的 Excel 拖曳進對話框，說：
    「幫我清掉缺考的資料，然後畫出各班數學成績的長條圖與常態分布圖。」
  • 背後原理： AI Agent 會「自動寫一段 Python 程式碼，在沙盒環境中執行，然後把圖表結果回傳給你」。

案例三：注重隱私的本機端開源 Agent

學校有很多機密資料（學生個資、輔導紀錄），絕對不可以上傳到雲端的 ChatGPT 或 Gemini！這時候我們需要「本機端」的 Agent。

Open Code (開源 Agent)

這類開源的 Agent 工具允許你將大語言模型 (如 Llama 3) 下載到自己的電腦或學校的伺服器上執行。

  • **完全斷網**也能運作。
  • 資料永遠不會離開你的電腦。
  • 是處理輔導紀錄分析、校內機密資料整理的最佳解方。
