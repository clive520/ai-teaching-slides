Firebase 即時連線教學

為您的網頁接上真正的資料庫

從靜態展示到全班即時互動的最後一哩路

為什麼需要 Firebase？

  • 靜態網頁的痛點：GitHub Pages 只能「展示」，不能「儲存」學生的輸入。
  • Firebase 是什麼？ Google 提供的強大後端服務，就像一面「所有人都能即時看到變化的便利貼牆」。
  • 效果：台下學生一按下送出，大螢幕的文字雲立刻長出新字！

1 建立專案與應用程式

  • 前往 Firebase Console，點擊「新增專案」。
  • 為專案取名 (例如 `my-ai-class`) 並完成建立。
  • 在專案首頁，點擊畫面中央的 「</>」(Web 圖示) 來註冊一個網頁應用程式。

2 取得您的設定碼 (身分證)

註冊完應用程式後，畫面會給您一段程式碼。

請找到裡面包含 `firebaseConfig` 的大括號 { ... } 區塊，把它完整複製下來。

const firebaseConfig = {
  apiKey: "AIzaSy...",
  authDomain: "...",
  databaseURL: "...",
  ...
};

3 開啟即時資料庫

  • 在左側選單點擊 建構 (Build) > Realtime Database。
  • 點擊「建立資料庫」。
  • 【關鍵安全設定】：在安全規則那一步，請務必選擇 「以測試模式啟動 (Test mode)」。
  • 這樣學生才能直接把字寫進資料庫裡！

4 貼入代碼，完成連線！

打開我們的 wordcloud.html 檔案，將剛剛複製的 firebaseConfig 貼到約第 112 行的位置，取代掉原本空的大括號。

魔法完成！

存檔並上傳後，您的文字雲就升級為「全網即時連線」版本了！
