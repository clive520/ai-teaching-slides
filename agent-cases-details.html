站在巨人的肩膀上：在自己動手寫程式之前，先看看市面上強大的現成工具。

為什麼需要現成 Agent？

在前面的課程中，我們學會了評估「什麼任務值得自動化」。許多有熱忱的老師，第一時間會想打開 Python 或 Zapier，嘗試自己寫一個 Agent 串接各種系統。

但**「避免重複造輪子」**是資訊科學中非常重要的一環。目前科技巨頭與開源社群已經開發出許多極度強大的通用型 Agent，它們可以直接授權存取你的電腦檔案、幫你寫程式、甚至幫你整理幾萬筆的 Excel 資料。

這堂課，我們將介紹三種不同定位的實用 Agent，幫助你在教育現場發揮最大的生產力。

Google Antigravity：強大的開發助理

Google Antigravity 是目前非常先進的開發型 Agent（也是我們製作這整套教學網站所使用的核心工具！）。它有別於只能「陪你聊天」的 ChatGPT，它具有真正的「執行力」。

它能做到什麼？

  • 存取本機檔案系統： 它可以直接讀取你資料夾裡的檔案，了解整個專案的架構。
  • 自動編寫與修改程式碼： 當你說「幫我把網頁上的按鈕變小」，它能自己找到該修改的 HTML 與 CSS 檔案並直接覆寫。
  • 終端機執行權限： 它可以代替你在終端機 (Terminal) 中輸入指令，例如自動呼叫 Git 把網頁上傳到 GitHub Pages。
👨‍🏫 教學現場應用情境：
如果資訊老師想要帶領學生做一個「線上測驗系統」專案。老師不需要從頭手把手教每一行 HTML，可以指導學生如何擔任「專案經理 (PM)」，用自然語言對 Antigravity 下達架構指令，讓 Agent 負責繁瑣的底層程式碼撰寫，學生則專注在系統邏輯與介面設計上。這正是未來軟體開發的新型態！

ChatGPT 資料分析 (原 Code Interpreter)

過去，老師如果要統計全校學生的「健康體適能成績」或「段考分數分布」，通常需要熟練 Excel 的各種樞紐分析表，甚至要學會寫 Python 爬蟲。現在，**ChatGPT 的「資料分析 (Data Analysis)」功能就是一個專為資料處理而生的 Agent**。

背後的運作原理

當你上傳一份 Excel 並要求「畫出數學成績低於 60 分的學生比例長條圖」時，ChatGPT 並不是「猜測」結果。它的背後隱藏了一個沙盒 (Sandbox) 環境：

  1. Agent 會自動理解你的需求，並寫出一段 Python 資料處理程式碼。
  2. Agent 在背景實際執行這段程式碼。
  3. 如果程式碼報錯 (Error)，Agent 會自己發現、自己 Debug、自己重寫。
  4. 最後將正確產出的圖表與 CSV 檔案回傳給老師。
👨‍🏫 教學現場應用情境：
學期末的「教學評鑑問卷」往往包含大量文字回饋與量表分數。老師可以直接將原始 CSV 丟給 Agent，請它：「幫我過濾掉無效填答，統計各項目的平均分數，並將文字回饋整理成正向與反向的文字雲圖表，最後輸出成一份 PDF 報告。」

注重隱私的本機端開源 Agent

教育現場最大的痛點之一，就是「學生個資與輔導紀錄絕對不可以上傳到公有雲端」。這意味著即使 ChatGPT 再強大，老師也不能把含有學生名字或家庭狀況的 Excel 丟給它分析。

本機端 Agent (Local Agent) 解決方案

這時候，我們就需要依賴像是 Open Code 這類的開源專案。它們允許你將大語言模型 (例如 Llama 3 或 Gemma) 下載到學校自己的伺服器，或老師自己性能較好的筆電上執行。

  • 完全斷網執行 (Offline-first)： 在沒有網路的情況下依然能運作，資料完全不外流。
  • 客製化流程： 可以針對學校內部的特殊表單，客製化專屬的自動化流程。
  • 安全性極高： 非常適合用來協助分析「輔導室的學生訪談紀錄」或「特教班的 IEP 個別化教育計畫」等高度敏感資料。

課後總結

透過這三個案例，我們可以看到 AI Agent 在不同維度上對教學現場的幫助：

  • 如果你需要**建置系統或開發教材** 👉 找 Antigravity 等開發型 Agent。
  • 如果你需要**處理龐大的報表與圖表** 👉 找 ChatGPT 資料分析。
  • 如果你處理的是**機敏個資** 👉 考慮建置 本機端開源 Agent。

老師不需要成為工程師，而是要成為一個**「善用各種頂尖 Agent 的超級 PM (專案經理)」**！
