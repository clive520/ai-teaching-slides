MCP 與 Skill

為 AI 大腦裝上「雙手」與「眼睛」

1. AI 最大的限制：大腦在雲端

  • 傳統的 ChatGPT 就像一個超級天才，但被關在一個沒有窗戶的房間（雲端伺服器）裡。
  • 它**看不見**你電腦裡的 Excel 報表。
  • 它**摸不到**你的硬碟，沒辦法幫你把檔案歸檔。
  • **解決方案**：給它接上一條「安全傳輸線」，這條線就叫 MCP！

2. 什麼是 MCP？

Model Context Protocol (模型上下文協議) 是一個標準化的連線規格。

  • 就像是 USB 插頭：以前每個 AI 系統都要自己寫外掛，現在有了 MCP，只要寫好一個工具（MCP Server），所有的 AI Agent 都可以「隨插即用」。
  • MCP 是連接「AI 大腦」與「你本地電腦資源」的關鍵橋樑。

4. 什麼是 Skill (技能)？

  • 在 MCP 架構下，我們可以把一包程式碼包裝成一個 Skill。
  • 例如：一個叫「網頁爬蟲」的 Skill，它知道如何打開網頁並抓取文字。
  • 當我們給 AI 下達任務時，AI 會先去自己的「工具箱」裡面翻找：「我有網頁爬蟲這個 Skill 嗎？有！那我就可以用它來完成任務。」

5. 安全機制：Human-in-the-loop

  • 把電腦交給 AI 操作，萬一它把 C 槽格式化怎麼辦？
  • 授權機制：透過 MCP，AI 每執行一個重大 Skill (例如：刪除檔案、執行指令)，都必須在畫面上彈出一個確認框。
  • 人類始終擁有最終決定權！(這就是所謂的 Human-in-the-loop)
