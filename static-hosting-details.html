靜態網頁部署空間 - 詳細圖解教學

完全零基礎！把你的網頁作品，從自己房間推向全世界的舞台。

為什麼我的網頁別人看不到？

這大概是所有剛接觸網頁設計的學生最常問的問題：「老師，我用 AI 寫好了一個超炫的網頁，為什麼我把上面那串 C:\Users\Desktop\index.html 複製給同學，他們都說打不開？」

讓我們用一個生動的比喻來解釋：

本機開發 (Localhost)：
就像你在「自己的房間」裡，用心組好了一座巨大的樂高模型。你自己每天看著它很開心，但因為這個模型放在你家，別人沒有你家的鑰匙，當然看不到這座模型。

網頁部署 (Deployment)：
為了讓大家都能欣賞你的作品，你需要把這座模型搬出房間，放到一個「公開的展覽館 (伺服器)」裡面。這個展覽館是 24 小時開放的，並且會配發一個專屬的「展場門牌號碼 (網址/Domain)」給你。從此以後，只要把門牌號碼給朋友，任何人都可以隨時走進展覽館欣賞你的網頁！

第一種展覽館：GitHub Pages

GitHub 是全世界最大的工程師社交平台，它提供了一個完全免費的展覽館服務，叫做 GitHub Pages。

你可以把它想像成「學校穿堂的免費公開佈告欄」。它非常穩定、經典，只要你願意把海報 (程式碼) 貼在上面，大家就能看到。

GitHub Pages 新手上架 5 步驟

雖然介面全是英文，但其實只要按幾個按鈕就能完成：

  1. 建立倉庫 (Repository)： 在 GitHub 首頁點擊右上角的 + 號，選擇 New repository。把這個想成是「申請一塊空的佈告欄」。
  2. 設定名稱與公開： 幫你的網頁取個英文名字 (例如 my-first-web)，並務必確認設定為 Public (公開)。
  3. 上傳檔案： 點擊 Upload files，把你在電腦裡寫好的 index.html 和所有圖片資料夾一起拖曳進去，按下綠色的 Commit changes 按鈕。
  4. 開啟 Pages 功能： 這是最重要的一步！點擊專案上方的 Settings (設定) 齒輪，在左邊側邊欄找到 Pages。
  5. 發布 (Deploy)： 在 Source 的 Branch 選單中，選擇 main 分支，然後按下 Save。等待約兩分鐘，頁面上方就會出現你專屬的網址了！

第二種展覽館：Vercel

如果你覺得每次修改網頁，都要手動上傳檔案到 GitHub 很麻煩，那麼你一定會愛上 Vercel。

Vercel 是一個現代化的部署平台，我們可以把它比喻成一個「擁有自動化系統的高級數位看板」。

什麼是 CI/CD (持續整合與部署)？

假設你把 Vercel (數位看板) 和你的 GitHub (原始檔信箱) 綁定在一起。

未來，只要你在電腦上修改了網頁，並把新的程式碼推送到 GitHub 信箱裡，Vercel 這個數位看板就會在 1 秒鐘內自動感應到！ 它會自動把你新的程式碼抓過來、重新編譯、然後無縫把舊網頁替換成新的網頁。

這個「只要改程式，網頁就自動更新」的魔法，在資訊界就叫做 CI/CD (Continuous Integration / Continuous Deployment)。它能為我們省下大量的繁瑣操作，是目前前端業界最流行的做法。

課後總結

對初學者來說，第一次成功把網頁部署到網路上，並用手機點開專屬網址的那一刻，是非常有成就感的！

  • 如果你是帶領學生做簡單的期末作業 👉 推薦使用 GitHub Pages，免費穩定且能順便學習版控。
  • 如果你想自己架設會頻繁更新的教學網站或部落格 👉 強烈推薦綁定 Vercel，體驗「按個存檔網頁就更新」的極速快感。
