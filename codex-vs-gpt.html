Codex 與 GPT 的差異

為什麼自動化需要專屬的「程式碼模型」？

1. 什麼是 GPT (對話模型)？

  • 定位：語言邏輯大師。
  • 優勢：擅長總結歸納、文字生成、情感分析、靈感發想。
  • 缺點：容易產生「幻覺 (Hallucination)」，為了討好使用者，可能會掰出不存在的資訊。
  • 代表：ChatGPT (一般模式), Gemini Pro, Claude 3 Sonnet
解說：日常對話時，AI 講錯一點點我們聽得懂就好；但程式碼只要錯一個標點符號，系統就會崩潰。

2. 什麼是 Codex (程式碼模型)？

  • 定位：嚴謹的工程師。
  • 訓練資料：海量的 GitHub 開源程式碼與技術文件。
  • 特性：理解「語法樹結構」，非常注重邏輯與因果關係。
  • 容錯率：零容錯率！程式碼一旦有語法錯誤就無法執行，因此這類模型極少產生幻覺。

3. 為何 AI Agent 需要寫程式？

  • 對話模型只能給你「計畫」，但它無法幫你「點擊滑鼠」。
  • Agent 的運作本質：遇到任務時，撰寫一小段 Python 或 JavaScript 腳本，然後在背景執行這個腳本來達成目的（例如：呼叫 API、自動整理檔案）。
  • 因此，Agent 底層必須依賴 程式碼模型，才能正確產出可執行的命令。
