老師與同學們，我們用 AI 寫好了精美的 HTML 跟 CSS，在自己的電腦上點開來看覺得超有成就感，但當你把那串網址傳給朋友時，對方卻只看到「無法連線」？這就是為什麼我們需要學習「部署 (Deployment)」。

為什麼我的網頁別人看不到？

自己房間 VS. 公開展覽館

把網頁當作「樂高模型」

  • 本機開發 (Localhost)： 就像你在**自己房間**組好了一座超酷的樂高。你自己看得很開心，但你的朋友沒鑰匙進不來你的房間。
  • 部署 (Deployment)： 就是把這個樂高模型，搬到**公開的展覽館** (伺服器)，並申請一個展場號碼 (網址 Domain)。
  • 這樣全世界只要輸入展場號碼，就可以隨時隨地看到你的作品！

跟學生強調：你電腦上的 C槽 路徑，別人是絕對點不開的。這是一個非常常見的新手痛點。

什麼是「靜態」網頁？

靜態網頁 (Static Website) 就像是一張**「印刷好的海報」**。

  • 不管今天是小明來看、還是小華來看，海報上的內容都長得**一模一樣**。
  • 它只有 HTML, CSS, JavaScript，沒有資料庫 (不能留言、不能登入帳號)。
  • 優點： 非常安全、速度極快，而且有很多大公司提供**「免費」**的展覽館讓我們放這種海報！

第一種展覽館：GitHub Pages

學校的經典免費佈告欄

  • 特色： 最老牌、最經典。幾乎全世界的工程師都有一個 GitHub 帳號。
  • 比喻： 就像學校穿堂的佈告欄，你只要把作品貼上去，它就會穩穩地在那邊讓大家看。
  • 適合誰： 想要交學校期末作業、展示個人靜態作品集、學習 Git 版控的新手。

缺點：更新速度有時比較慢，介面稍微硬核一點。

第二種展覽館：Vercel

自動更新的數位看板

現代極速高鐵，懶人福音

  • 特色： 目前全球前端工程師最愛用的服務，介面超美、速度極快。
  • 比喻： 它是一台**「連線的數位看板」**。你只要把新的檔案放進信箱，這台機器就會在一秒內「自動幫你把新海報換上去」(這就叫做 CI/CD)。
  • 適合誰： 想要無痛更新網頁、使用現代框架 (如 React/Next.js) 的開發者。
